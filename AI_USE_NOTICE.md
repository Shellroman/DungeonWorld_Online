# AI Use Disclosure / 생성형 AI 사용 안내

## English

Generative AI was used as an **assistive development tool** during the development of Dungeon World Online.

It was used for tasks including code drafting and review, debugging, regression-test authoring, Korean/English UI wording and translation editing, documentation, and review. Final product decisions, rules interpretation, source integration, test verification, and release decisions were made by the project creator, **ShellRoman**.

This disclosure is provided for transparency. The use of AI does not alter the licenses or attribution requirements that apply to third-party material such as Dungeon World, the Korean public edition, or Unlimited Dungeons / Distant Shore Pack material.

The released application does not include an integration that sends game data or user input to OpenAI, ChatGPT, or another external generative-AI service.
