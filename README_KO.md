# Dungeon World Online v1.0.0

**첫 공개 배포판**입니다. Dungeon World 1판을 위한 비공식 온라인 플레이 보조 도구로, GM 한 명이 Windows 런처에서 캠페인을 열고 플레이어는 브라우저로 참가합니다.

- 앱 버전: **1.0.0**
- DB schema: **20**
- DWPack format: **1**
- Windows: **x64**
- BUILD_ID: **bbf02338d0f83dc9**


## 주요 기능

- **English / 한국어**: 기본 언어는 English이며, 런처와 게임 화면에서 언제든 한국어로 전환할 수 있습니다. 설정, 도움말과 기본 직업·종족·행동·주문·몬스터도 두 언어로 제공합니다.
- **개인별 화면 언어**: 같은 캠페인에서도 각 사용자가 원하는 UI 언어를 선택할 수 있습니다. 사용자가 직접 작성한 자료는 원래 언어를 유지합니다.
- **활성 캠페인만 참가**: 저장되어 있어도 GM이 현재 열지 않은 캠페인은 신규 참가, 재접속, 직접 API 접근에서 차단합니다.
- **플레이어 정원**: 캠페인을 만들 때 GM을 제외한 플레이어 정원을 2~8명으로 정합니다. 기본값은 4명이며 서버에서도 정원을 강제합니다.
- **캐릭터 관리**: 능력치, HP, 장갑, 피해, 인연, 행동, 주문, 예비, 메모, 성장, 추가 획득 출처를 관리합니다.
- **행동 효과 / 타직업 획득**: 주문 추가 습득, 주문 요구 레벨 변경, 다른 직업 행동·주문 체계 획득 등을 설명형 UI에서 설정하고 선택할 수 있습니다.
- **주문 안전성**: 미분류 주문은 일반 주문 선택으로 얻을 수 없고, 명시적인 종족/GM 특수 경로에서만 사용됩니다.
- **텍스트 중심 인벤토리**: 이름·종류·수량·무게·태그와 필요한 수치만 구조화합니다. 탄약은 무기와 분리된 `탄약 / Ammo` 물건으로 관리합니다.
- **GM 도구**: NPC, 몬스터/도감, 빠른 제작, 세션/플레이 기록, 참가자 관리, 규칙, DWPack과 시스템 설정을 제공합니다.
- **선택형 확장직업**: Unlimited Dungeons / Distant Shore 계열 예시는 기본 캠페인에 자동 추가하지 않고 별도 선택 팩으로 제공합니다.
- **파일 기반 사운드**: 호스트가 업로드한 오디오 파일로 BGM과 효과음을 사용합니다. 외부 동영상 링크 기반 사운드 기능은 포함하지 않습니다.
- **LAN / 초대코드 / 재접속**: 같은 네트워크 검색과 초대코드, 일회용 재접속 흐름을 지원합니다.
- **DWPack**: 직업·종족·주문·행동·확장직업·몬스터·NPC·일부 규칙을 캠페인 사이에서 옮길 수 있습니다.
- **데이터 기반 주문 운용 규칙**: 마법사/사제라는 직업명을 코드에 고정하지 않고, 주문 습득·준비·한도 규칙을 직업 데이터로 저장합니다. 타직업 주문 체계 획득과 행동을 통한 중첩 접근도 원본 직업의 주문 규칙을 따라갑니다.
- **규칙 계산 수정**: 하중은 근력 원점수가 아니라 STR 수정치를 사용하고, 동전 무게의 클라이언트/서버 계산을 일치시켰으며, 피해 최솟값 0과 몬스터 고굴림/주사위 프리셋 판정을 바로잡았습니다.
- **몬스터 도감 공개 제어**: 영문 공개 항목을 완전한 문장으로 정리하고 GM이 한 번에 모든 항목을 공개하는 **전부 공개** 기능을 추가했습니다.
- **English 몬스터 데이터/캐시 안정화**: 154개 기본 몬스터에 명시적인 English 표시 데이터를 제공하고, 번역 카탈로그를 BUILD_ID별로 새로 불러와 이전 캐시 때문에 한국어가 섞이는 문제를 방지합니다.
- **사용자 제작 데이터 번역 보호**: 기본 콘텐츠의 English 번역은 `builtin` 출처가 확인된 데이터에만 적용하며, 커스텀 직업·종족·행동·주문·몬스터·확장직업은 작성한 문자열을 그대로 유지합니다.

## 같은 장소 / 원격 플레이

같은 집·모임 장소처럼 **같은 공유기/Wi-Fi/LAN**을 사용하는 경우에는 런처의 **같은 네트워크 캠페인 찾기** 또는 해당 네트워크용 초대코드를 사용하면 됩니다.

서로 다른 집처럼 **서로 다른 네트워크**에서 플레이할 때 Dungeon World Online 자체가 중앙 중계 서버를 제공하지는 않습니다. **Tailscale, ZeroTier, Radmin VPN** 같은 가상 LAN/VPN 도구로 GM과 플레이어를 같은 가상 네트워크에 연결한 뒤 사용하세요. GM이 호스트 서버를 실행하고, VPN 경로에 맞는 초대코드 또는 GM의 VPN 주소와 캠페인 코드를 플레이어에게 전달하면 됩니다. VPN 종류에 따라 LAN 자동 검색이 동작하지 않을 수 있으므로 그때는 서버 주소를 직접 입력하는 방식이 가장 확실합니다.

원격 플레이 중에는 **GM의 PC와 Dungeon World Online 호스트 서버가 계속 실행 중이어야 하며**, Windows 방화벽이나 VPN 자체의 네트워크 규칙에서도 연결이 허용되어야 합니다.

## 데이터 호환

DB schema는 **20**입니다. 이전 개발판의 schema 13~19 캠페인을 위한 순차 migration 경로를 유지합니다. schema 18에서 무기에 직접 저장되었던 탄약 값은 schema 19에서 별도 `탄약 / Ammo` 항목으로 안전하게 분리되고, schema 20에서는 캠페인 플레이어 정원을 추가합니다. 기존 캠페인은 현재 활성 플레이어 수를 고려해 4~8명 범위로 안전하게 이관합니다.

장기 캠페인을 업데이트하기 전에는 호스트 데이터 폴더 전체를 한 번 백업하는 것을 권장합니다.

Windows 런처의 공개 데이터 폴더 이름은 `DungeonWorldOnline`입니다. 이전 개발판의 데이터 폴더가 있고 새 폴더가 아직 없다면 런처가 한 번 자동 이관을 시도하며, 권한 문제로 이관할 수 없을 때는 데이터 손실을 피하기 위해 기존 폴더를 계속 사용합니다.
